# 周报汇总规则

> 将多篇日报内容整理为周报 4 个板块。

## 工作流程

```
多篇日报（Markdown 内容）
       ↓
Step 1：按日期排序
       ↓
Step 2：逐篇提取关键信息（项目、问题、心得、计划）
       ↓
Step 3：按板块汇总、去重、归纳
       ↓
Step 4：升维提炼（日报是记录，周报是总结）
       ↓
周报结构化数据（参考 周报架构.md）
```

## 各板块汇总方法

### 📋 本周重点工作

**原则：按项目归类，不逐天罗列。**

原始数据：各日报的"今日进展"板块内容

汇总步骤：
1. 提取所有日报中出现的 `project` 名称
2. 按项目分组，合并多日进展
3. 统计该项目本周的：
   - 完成的 case 数 / 功能点
   - 发现的 Bug 数（含已修复、未修复）
   - 关键里程碑（评审通过、环境就绪、需求变更等）
   - 整体进度状态（已完成 / 进行中 / 阻塞）
4. 撰写一句话概括

**示例：**

```
日报1: 惊喜红包券测试 70%，覆盖 20 条用例，1 个 Bug
日报2: 惊喜红包券测试 100%，覆盖 60 条用例，共 3 个 Bug
      资损核对计划评审通过
      编写核对用例 3/6

→ 汇总：
惊喜红包券测试：本周完成全量测试（60 条用例），
发现 3 个 Bug（1 个已修复），测试进度 100%。
资损核对计划：完成编写与评审，核对用例编写 3/6。
```

### ⚠️ 遇到的问题与风险

**原则：区分已解决/遗留中/风险，关注趋势。**

原始数据：各日报的"遇到的问题与风险"板块

汇总步骤：
1. 提取所有日报中的 `problems[]`
2. 按问题内容去重（同一问题可能在多篇日报中出现）
3. 区分状态：
   - ✅ **已解决**：问题已修复或已关闭
   - 📌 **遗留中**：跨天持续存在、尚未解决
   - ⚠️ **风险**：潜在风险项
4. 对遗留问题，总结当前进展和后续计划

**示例：**

```
日报1: 环境不稳定（风险）、上游离线表未到位（待跟进）
日报2: 环境不稳定（风险，持续）、上游离线表已确认时间
日报3: 环境已恢复

→ 汇总：
✅ 已解决：测试环境不稳定问题（持续 3 天），已于周四恢复
📌 遗留中：上游离线表已确认提供时间，待数据到位后执行核对
```

### 💡 经验沉淀

**原则：提取最重要的 1-2 个收获，做方法论升华。**

原始数据：各日报的"成长心得"板块

汇总步骤：
1. 提取所有日报中的 `learnings[]`
2. 保留最有价值的 1-2 个（按 `is_key_takeaway` 标记或 AI 判断）
3. 做三层升华：
   - **从具体到抽象**：从"遇到 X 问题" 升华到 "X 这类问题的通用处理思路"
   - **从实践到方法**：从"用了 Y 方法" 升华到 "Y 方法可适用于 Z 类场景"
   - **从个人到团队**：从"我学会了" 升华到 "团队可以这样复用"
4. 如果多篇日报的心得主题相近，合并为一条更强的 insight

**示例：**

```
日报1: 并发扣减场景加深了对乐观锁的理解 → 可沉淀 CheckList
日报2: AI 辅助排查日志提升了效率 → 可沉淀 SOP

→ 汇总（升华后）：
1. 本周在红包券测试中，通过覆盖并发竞争场景，
   对分布式事务在金额扣减中的应用有了更深的理解。
   后续可以将这类并发测试场景设计思路沉淀为
   通用的「金额类功能测试 CheckList」。

2. 尝试用 AI 辅助异常日志分析和脚本边界处理，
   提升了排查效率。可以将「排查流程 + AI 辅助」
   的方法沉淀为团队 SOP。
```

### 📅 下周计划

**原则：去重合并，形成下周目标清单。**

原始数据：各日报的"明日计划"板块 + 用户补充

汇总步骤：
1. 提取各日报的明日计划中**属于下周**的任务
2. 按项目归类合并
3. 去重（同一个任务可能在多篇日报中重复出现）
4. 转化为下周目标（不仅仅是待办清单，要有目标和产出描述）

**示例：**

```
日报1: 继续测试 → 资损核对用例 3/6
日报2: 完成测试 → 资损核对用例 6/6 → 验证环境修复
日报3: 测试报告初稿 → 核对执行

→ 汇总：
1. 完成资损核对用例编写（6/6）并执行核对验证
2. 输出惊喜红包券测试报告
3. 跟进上游离线表到位后的核对工作
```

## 补充字段：`core_summary`

汇总完所有板块后，写一句本周核心总结，格式：

`本周主要推进 [项目名]，完成 [关键交付]，[成果/问题概述]。`

例：`本周主要推进惊喜红包券全量测试（100% 完成），完成资损核对计划评审和用例编写，发现 3 个 Bug 均已修复，测试报告待下周初稿输出。`
